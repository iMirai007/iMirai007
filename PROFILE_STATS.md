# GitHub Analytics

| Metric | Definition |
| --- | --- |
| Lifetime contributions | Contribution credits reported by GitHub through yesterday. |
| Owned repositories | Current owned repositories, excluding forks. |
| Private repositories | The private subset of owned repositories. |
| Contribution calendar | Daily contribution credits over the last 365 completed UTC days. |

Repository names and source code are not displayed. Contribution credits are not a count of unique commits or shipped products. The refresh date indicates when GitHub last supplied the statistics.
